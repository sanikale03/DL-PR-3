# CV PR3 Dataset

This self-contained educational image pack supports the classical OpenCV portions of PR 3:
- morphology / salt-and-pepper noise
- bitwise masks
- grayscale and colour histograms
- brightness / contrast experiments
- preprocessing examples

The YuNet and YOLO tasks require real photographs containing faces / COCO objects.
The notebook therefore includes optional download cells for public test images and
automatically downloads the YuNet ONNX model when internet access is available.

For best grading results, add 3–4 of your own photos to this folder:
- at least one side-profile face
- at least one partially occluded / sunglasses face
- 2–3 photos with multiple everyday COCO objects
